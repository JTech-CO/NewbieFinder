<Description>
NewbieFinder - 치지직에서 지금 방송 중인 소규모 스트리머 찾기

치지직의 기본 탐색 화면은 인기 방송과 추천 방송을 중심으로 구성됩니다. 그래서 시청자와 팔로워가 적은 스트리머는 방송을 켜도 눈에 띄기 어렵습니다. NewbieFinder는 치지직이 공개한 라이브 정보를 읽기 전용으로 훑어, 사용자가 정한 시청자 수·팔로워 수 상한을 만족하는 방송만 따로 모아 보여 줍니다.

치지직 탭에서 툴바 아이콘을 누르면 별도의 탐색 화면이 새 탭으로 열립니다. 로그인은 필요하지 않습니다. 네이버 계정, 로그인 쿠키, 액세스 토큰을 요구하지 않으며 별도의 서버 없이 브라우저 안에서만 동작합니다.

<Key Features>
- 규모 조건으로 탐색: 시청자 수는 1~30명, 팔로워 수는 1~100명 범위에서 상한을 정합니다. 두 조건을 함께 켜면 두 수치를 모두 만족하는 방송만 남습니다. 조건을 바꾸면 이미 확인한 데이터에서 즉시 다시 걸러 내므로 기다릴 필요가 없습니다.
- 조건에 기대는 최근 정렬: '최근 시작 순'은 시청자 또는 팔로워 조건이 하나 이상 켜져 있을 때만 사용할 수 있습니다. 규모 조건 없이 최근 순만 보면 방송을 막 켠 대형 채널이 결과를 덮어 버리기 때문입니다.
- 어디까지 확인했는지 밝히는 결과: '시청자 10명 이하 라이브를 빠짐없이 확인했습니다'와 '지금까지 라이브 300개를 확인했습니다'를 구분해서 표시합니다. 예산이나 오류로 탐색이 끊기면 부분 결과임을 명시하고, 남은 구간은 '계속 탐색'으로 이어서 확인할 수 있습니다.
- 카드 한 장에 정리된 정보: 방송 제목, 채널명, 현재 시청자 수, 팔로워 수, 방송 시작 후 경과 시간, 카테고리를 함께 보여 줍니다. 카드를 누르면 해당 채널의 치지직 페이지가 새 탭으로 열립니다.
- 로그인 없이 동작: 네이버 로그인 쿠키(NID_AUT, NID_SES 등)와 계정 정보를 읽지 않습니다. 모든 요청은 인증 정보 없이 나가며, 로그인 상태와 관계없이 같은 결과를 보여 줍니다.
- 요청을 아껴 쓰는 구조: 채널 조회는 동시 4건을 넘지 않고, 한 번의 탐색에서 라이브 목록 20페이지와 채널 300건을 넘지 않습니다. 확인한 정보는 짧게 캐시하고, 새로고침에는 20초 쿨다운을 둡니다. 주기적으로 백그라운드에서 자동 수집하는 동작은 없습니다.
- 데이터가 이상하면 멈춥니다: 응답 형식이 예상과 다르면 값을 추측해서 채우지 않고 탐색을 중단한 뒤 진단 코드를 표시합니다. 잘못된 결과를 맞는 것처럼 보여 주지 않습니다.
- 성인 방송 제외: 성인 표시가 된 방송은 결과에 넣지 않습니다.
- 접근성과 키보드: 모든 조작을 키보드로 할 수 있습니다. 스위치와 슬라이더에 적절한 ARIA 정보를 제공하고, 상태를 색만으로 전달하지 않으며, 움직임 줄이기 설정을 따릅니다.
- 외부 코드 없음: 원격 스크립트, CDN, 외부 폰트, 분석·광고 SDK를 쓰지 않습니다. 실행되는 코드는 모두 확장 패키지 안에 들어 있습니다.

<Single Purpose>
NewbieFinder는 한 가지 목적만 수행합니다. 치지직에서 현재 라이브 중인 방송 가운데 사용자가 정한 시청자 수·팔로워 수 상한을 만족하는 소규모 방송을 찾아 목록으로 보여 주는 것입니다. 그 외의 일은 하지 않습니다.

방송 재생, 채팅, 팔로우, 구독, 알림 등록 같은 기능은 제공하지 않으며, 치지직 페이지의 화면을 바꾸지도 않습니다. 확장은 치지직 페이지에 코드를 주입하지 않고 자체 탐색 화면만 새 탭으로 엽니다. 모든 통신은 브라우저와 치지직 서버 사이에서 직접 이루어집니다. NewbieFinder 서버는 존재하지 않고, 계정도 없으며, 사용 기록을 수집하는 분석 도구도 넣지 않았습니다.

이 확장이 읽는 정보는 치지직이 라이브 목록 화면에서 이미 공개하고 있는 방송 제목, 채널명, 현재 시청자 수, 방송 시작 시각, 카테고리, 그리고 채널 페이지에 공개된 팔로워 수입니다. 사용자가 어떤 방송을 보았는지는 기록하지 않습니다.

<Permission Justifications>

<declarativeContent>
툴바 아이콘을 치지직(https://chzzk.naver.com)을 보고 있을 때만 활성화하기 위해 사용합니다. 다른 사이트에서는 아이콘이 비활성 상태로 남아 클릭되지 않습니다.

declarativeContent는 브라우저가 URL 조건만 대조하는 선언적 방식입니다. 확장은 페이지의 주소가 조건에 맞는지 여부만 브라우저에 맡기며, 페이지 내용이나 DOM을 읽지 않고 열람 기록도 받지 않습니다. 같은 결과를 activeTab이나 콘텐츠 스크립트로 만들 수도 있지만, 그 경우 페이지 내용에 접근할 수 있는 권한을 함께 요구하게 되므로 더 좁은 이 방식을 선택했습니다.

<storage>
사용자가 정한 탐색 조건(시청자 수 사용 여부와 상한, 팔로워 수 사용 여부와 상한, 최근 시작 순 사용 여부)을 저장해 다음에 확장을 열었을 때 그대로 복원하기 위해 사용합니다. 함께 저장하는 것은 방금 확인한 공개 라이브 목록과 채널별 팔로워 수의 짧은 캐시, 그리고 새로고침 쿨다운 상태입니다.

캐시를 두는 이유는 요청을 줄이기 위해서입니다. 라이브 목록은 45초, 채널 팔로워 수는 15분이 지나면 새로 확인하며, 캐시 총량과 보관 기간에 상한을 두고 오래된 항목부터 정리합니다.

저장되는 모든 값은 사용자의 브라우저 안에만 남습니다. 어떤 저장 항목도 외부로 전송되지 않으며, 확장을 삭제하면 함께 지워집니다. 로그인 쿠키, 세션, 방문 기록, 개인 식별 정보는 저장하지 않습니다.

<Host permission: https://api.chzzk.naver.com/*>
조건에 맞는 방송을 찾기 위해 치지직의 공개 정보를 읽는 데 사용합니다. 요청하는 곳은 두 가지뿐입니다.

- GET /service/v1/lives: 현재 라이브 중인 방송 목록과 각 방송의 시청자 수, 시작 시각, 카테고리
- GET /service/v1/channels/{channelId}: 팔로워 조건 판정에 필요한 채널의 공개 팔로워 수

요청은 사용자가 탐색 화면을 열거나, 새로고침을 누르거나, 계속 탐색을 누르거나, 기존 데이터로 답할 수 없는 조건으로 바꿨을 때만 발생합니다. 사용자가 화면을 닫으면 진행 중인 요청은 즉시 중단됩니다. 주기적으로 도는 백그라운드 수집은 없습니다.

모든 요청은 credentials를 omit으로 지정해 쿠키를 보내지 않습니다. Authorization 헤더를 붙이지 않고, User-Agent나 Origin, Referer를 위장하지 않으며, 예상하지 않은 다른 호스트로의 리다이렉트를 따라가지 않습니다. 서버가 접근을 제한하면(401, 403, 429) 우회를 시도하지 않고 탐색을 중단합니다.

통신은 브라우저와 치지직 서버 사이에서만 이루어집니다. 제3자 서버를 경유하지 않고, 수집한 정보를 어디에도 업로드하지 않습니다. 확장 안에는 개인정보 처리 방침이 함께 들어 있습니다.

<Data Usage>
NewbieFinder는 다음 항목을 수집하지 않습니다: 개인 식별 정보, 건강 정보, 금융 정보, 인증 정보, 개인 통신 내용, 위치, 웹 열람 기록, 사용자 활동, 웹사이트 콘텐츠.

브라우저에 저장하는 것은 사용자가 직접 설정한 탐색 조건과 공개 방송 정보의 짧은 캐시뿐이며, 둘 다 사용자의 기기를 벗어나지 않습니다. 판매하거나 제3자에게 제공하지 않고, 확장의 단일 목적과 무관한 용도로 사용하지 않으며, 신용도 평가나 대출 목적으로 사용하지 않습니다.

<Notes>
NewbieFinder는 NAVER 또는 CHZZK의 공식 서비스가 아닌 독립적인 브라우저 확장 프로그램입니다. 공식 로고나 워드마크를 사용하지 않으며, 공식 제품으로 오인될 수 있는 명칭을 쓰지 않습니다.
