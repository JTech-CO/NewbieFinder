# 개인정보 처리방침 (Privacy Policy)

- 대상 제품: NewbieFinder v1.0.0 (Chrome 확장 프로그램, Manifest V3)
- 최종 갱신일: 2026-08-11
- 공개용 페이지: [`privacy.html`](../privacy.html): 같은 내용의 HTML 판입니다. **한쪽을 고치면 다른 쪽도 함께 고쳐 주세요.**

NewbieFinder는 치지직에서 현재 라이브 중인 소규모 방송을 찾기 위한 확장 프로그램입니다.
이 문서는 확장이 무엇을 저장하고, 어디에 저장하며, 언제 지우는지를 설명합니다.

**요약: NewbieFinder는 개인정보를 수집하지 않습니다. 저장하는 값은 사용자가 직접 설정한 필터 조건과 짧은 기간의 공개 라이브 캐시뿐이며, 모두 사용자의 브라우저 안에만 있습니다. 외부로 전송하는 데이터가 없습니다.**

## 2. 수집하는 것

### 2.1. 필터 설정

사용자가 Finder 화면에서 직접 설정한 값입니다.

- 시청자 수 조건 활성화 여부와 상한 (`1~30`)
- 팔로워 수 조건 활성화 여부와 상한 (`1~100`)
- 최근 시작 순 정렬 사용 여부
- 테마 값 (v1은 다크 고정)

`chrome.storage.sync` 에 저장하므로, 같은 Google 계정으로 Chrome 동기화를 사용 중이라면 다른 기기에도 설정이 함께 반영될 수 있습니다. 동기화되는 값은 위의 숫자와 참/거짓 값뿐이며 방송 목록이나 개인 식별 정보는 포함되지 않습니다.

### 2.2. 공개 라이브·채널 정보 캐시

같은 방송 목록을 짧은 시간 안에 반복해서 요청하지 않기 위한 임시 캐시입니다. 치지직이 누구에게나 공개하는 값만 담습니다.

- 방송 제목, 현재 시청자 수, 방송 시작 시각, 썸네일 URL, 카테고리명
- 채널명, 채널 ID, 채널 이미지 URL, 인증 표시 여부
- 채널별 팔로워 수

### 2.3. 세션 상태

새로고침 쿨다운과 중복 요청 방지를 위한 값입니다. 브라우저를 닫으면 사라집니다.

## 3. 수집하지 않는 것

- **네이버 계정 정보와 로그인 상태**를 읽지 않습니다. 확장은 로그인 여부와 무관하게 동작합니다.
- **쿠키를 읽지 않습니다.** `cookies` 권한을 요청하지 않으며, 모든 API 요청은 `credentials: "omit"` 으로 보내 인증 정보가 실리지 않도록 명시합니다.
- **브라우저 방문 기록과 탭 내용을 읽지 않습니다.** `history`, `tabs`, `activeTab` 권한을 사용하지 않고 Content Script도 없습니다. 치지직 페이지의 DOM에 접근하지 않습니다.
- **사용 분석·광고·오류 수집 SDK를 넣지 않습니다.** Google Analytics, Sentry 같은 외부 telemetry가 없습니다.
- **어떤 형태의 프로필링이나 개인화 추천도 하지 않습니다.**
- 개발 모드 디버그 로그에도 원시 응답 전체, 요청 헤더, 쿠키, IP, 방문 기록을 남기지 않습니다.

## 4. 저장 위치

모든 데이터는 **사용자의 로컬 브라우저 저장소**에만 있습니다.

| 저장소 | 담는 값 |
|---|---|
| `chrome.storage.sync` | 필터 설정 (Chrome 동기화 정책을 따릅니다) |
| `chrome.storage.local` | 라이브·채널 캐시, 마지막 갱신 시각, 안내 닫힘 여부 |
| `chrome.storage.session` | 새로고침 쿨다운, 요청 잠금 |
| 브라우저 HTTP 캐시 | 썸네일 이미지 (확장이 별도로 이미지를 내려받아 보관하지 않습니다) |

NewbieFinder는 자체 서버, 서버리스 프록시, 데이터베이스를 운영하지 않습니다. IndexedDB는 v1에서 사용하지 않습니다.

## 5. 보존 기간과 삭제

| 데이터 | 보존 규칙 |
|---|---|
| 라이브 캐시 | 신선 45초, 이후 5분까지 오래된 데이터로만 사용하고 그 뒤 폐기 |
| 채널(팔로워) 캐시 | 신선 15분, 이후 24시간까지 오래된 데이터로만 사용하고 그 뒤 폐기 |
| 필터 설정 | 사용자가 변경하거나 확장을 제거할 때까지 |
| 세션 상태 | 브라우저 종료 시 삭제 |

캐시 총량에도 상한을 두어(채널 2,000건, 라이브 후보 1,500건) 오래된 항목부터 정리합니다. `unlimitedStorage` 권한을 요청하지 않습니다.

### 확장을 제거하면

`chrome://extensions` 에서 NewbieFinder를 삭제하면 `chrome.storage.sync`, `chrome.storage.local`, `chrome.storage.session` 에 저장된 값이 **Chrome에 의해 함께 삭제됩니다.** 확장이 브라우저 밖에 남기는 데이터는 없으므로 별도로 지워야 할 파일이나 계정이 없습니다.

설정만 초기화하고 싶다면 확장을 삭제하지 않고 Finder 화면에서 조건을 기본값(시청자 조건 켜짐 / 상한 10명)으로 되돌리면 됩니다.

## 6. 제3자 전송

**NewbieFinder는 어떤 데이터도 제3자에게 전송하거나 판매하지 않습니다.**

확장이 네트워크 요청을 보내는 대상은 다음 한 곳뿐입니다.

```text
https://api.chzzk.naver.com/*
```

이 요청은 **읽기 전용**이며, 현재 라이브 목록과 채널의 공개 정보를 가져오기 위한 GET 요청입니다. 사용자의 설정값이나 개인 식별 정보를 이 요청에 실어 보내지 않습니다.

- 쿠키와 `Authorization` 헤더를 설정하지 않습니다.
- `User-Agent`, `Origin`, `Referer` 를 위장하지 않습니다.
- 예상하지 않은 다른 호스트로의 리다이렉트를 따르지 않습니다 (`redirect: "error"`).
- 요청은 사용자가 Finder를 열거나 새로고침 버튼을 눌렀을 때만 발생합니다. 주기적인 백그라운드 수집이 없습니다.

썸네일 이미지는 브라우저가 `*.pstatic.net`, `*.akamaized.net` 에서 직접 불러옵니다. 이 과정은 일반 웹 페이지에서 이미지를 볼 때와 같으며, 확장이 이미지를 내려받아 보관하지 않습니다.

## 7. 아동 개인정보
